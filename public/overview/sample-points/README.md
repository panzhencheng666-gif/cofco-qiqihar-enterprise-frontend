# Sample-point role icons

The three SVG files in this directory were authored specifically for this repository on 2026-08-29. They use only hand-written SVG geometry and repository color tokens; no external image, font, tracing source, or downloaded asset is incorporated.

- `production-rice.svg`: rice stalk for production observations.
- `market-bank.svg`: storefront and price bars for market observations.
- `logistics-car.svg`: freight truck for logistics observations.

They are presentation-only. The surrounding visible text or interactive control supplies the accessible name, so rendered `<img>` elements remain decorative (`alt=""` and, where needed, `aria-hidden="true"`).
