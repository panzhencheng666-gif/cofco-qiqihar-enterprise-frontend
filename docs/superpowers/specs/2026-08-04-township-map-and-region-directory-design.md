# 乡镇地图与地区名录重构设计

## 目标

总揽监测地图最深展示到乡镇。行政村不再作为地图边界、点位或可下钻层级出现，而是作为所选地区的后端主数据，在右侧综合详情中提供数量和可搜索名称下拉。

## 地图几何与交互

- 总体、地市、区县和乡镇继续使用后端行政区边界。
- 乡镇展示几何在进入前端前必须满足：有效多边形、位于所属区县内、无未归属交互碎片。
- 展示几何、标签、鼠标命中和选中状态必须共用同一个“地区代码 + 几何分量”身份，禁止一个地区的交互驱动其他地区或远端分量。
- 鼠标指向哪个乡镇，只将该乡镇的完整可交互几何变为金色；移开立即恢复。其他乡镇不得出现条块、侧壁或颜色响应。
- 默认地图只保留一层父级外边界和一层同级内部边界，不重复绘线，不渲染行政村。
- 乡镇为终点层级：双击乡镇、详情按钮和地区导航均不得再进入行政村地图。

## 地区信息栏

“区域概况”保留行政层级，删除行政区划代码、审核记录和最新填报时间，改为以下动态信息：

- 区县数量及可搜索名称下拉；
- 乡镇数量及可搜索名称下拉；
- 行政村数量及可搜索名称下拉。

区县名称按所选地市的直接子级读取；乡镇、行政村名称通过现有 `/api/v1/overview/locations` 按所选地区递归范围读取。选择乡镇时，行政村名录仍可查询，但不会改变地图层级。无数据时显示 `0` 和“暂无地区”。

## 数据与性能

- 名称、数量和业务指标全部来自后端接口，不在前端写死。
- 区县、乡镇、行政村名录并行请求；行政地理缓存沿用五分钟缓存，业务指标沿用五秒缓存。
- 名录搜索在已加载结果上本地过滤，不因每次键入重复请求后端。

## 验收标准

1. 总体 → 地市 → 区县 → 乡镇可以逐级进入，乡镇之后不可再下钻地图。
2. 三市全部 232 个乡镇均可通过地区导航到达并显示名称。
3. 任一乡镇悬停时仅该乡镇变金色，诊断计数中凸起/高亮区域为 1，其他地区为 0。
4. 默认边线无重复段，地图无行政村边界、行政村点位和行政村标签。
5. 信息栏三类数量与后端返回一致，名称可搜索，选择不同地区后同步刷新。
6. 目标单元测试、TypeScript 构建和 1920×1080 浏览器逐级实测通过，控制台无相关错误。

## 明确不做

- 不补造剩余 64 个行政村多边形；
- 不再调整行政村三维地图；
- 不使用静态图片承载行政边界或业务数据。
