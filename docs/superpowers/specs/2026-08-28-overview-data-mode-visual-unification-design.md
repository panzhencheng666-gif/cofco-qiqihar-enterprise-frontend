# 总揽监测地区数据与供需平衡视觉统一设计

## 目标

在不改变正式数据契约、计算规则、地图交互和样本点默认模式的前提下，解决地区数据/供需平衡模式中导航按钮遮挡指标、供需表格过大且视觉割裂的问题，并让两个模式与样本点总揽的蓝色玻璃态指挥舱保持同一视觉语言。

## 已确认的业务要求

- `样本点` 继续作为默认模式，地图、图例和样本网络工具保持原行为。
- `地区数据` 保留播种面积、单产、总产、结构调整增减和增减比率五项指标。
- `供需平衡` 同时展示核心指标卡和正式完整表格，不能只用指标卡替代表格。
- `返回业务目录`、`选择地区` 与模式切换属于工具栏，不得覆盖指标或表格。
- 缺失正式数据不能伪造成零。

## 布局

### 工具栏

模式切换从数据面板内部移出，与 `返回业务目录`、`选择地区` 组成独立工具栏。样本点和地区数据模式中，工具栏位于顶部 KPI 面板下方；供需平衡模式中，顶部不再放置数据面板，工具栏紧接页面标题区并限制在地图可见区域内。切换按钮继续使用现有分段按钮语言，并保持清晰的 `aria-pressed` 状态。

### 地区数据

使用与样本点 KPI 一致的单层玻璃态面板。面板标题显示地区、年度和品种；五个指标等宽排列。正式值使用高对比数字，单位独立显示，对比说明位于面板底部。

### 供需平衡

使用固定右侧业务详情栏，不再占用地图上方的大面积空间。右栏宽度约 540px，从标题区下方延伸至页面底部；地图画布同步缩窄到右栏左侧，不以浮层方式遮盖地图。右栏分为两层：

1. 顶部核心指标卡：产量、总供给、总需求、期末库存、需求供给比；使用两列紧凑网格，从正式供需行按代码选取，不复制或另算数据。
2. 下部完整表格：保留后端返回的全部行，使用项目、数值、单位三列。正式口径作为项目名称下方的第二行说明，避免窄栏出现横向拥挤。表头固定，只允许表体纵向滚动，不产生横向滚动。

该右栏属于总揽监测内部布局，不新增独立页面、弹窗或抽屉。右栏打开时图例、工具栏和地图标签仍限制在缩窄后的地图区域内。

## 数据显示语义

- 有 `display` 时原样显示后端正式格式化值。
- `MANUAL` 缺值显示 `待填报`。
- `AUTO` 或 `DERIVED` 缺值显示 `计算条件未完整`。
- `RATIO` 缺值显示 `不可计算`。
- 请求错误继续使用现有 `role="alert"`，加载中继续使用 `role="status"`。

## 组件边界

- `OverviewDataModeTabs` 只负责三模式切换，始终渲染在 `OverviewCommandCenter` 的工具栏插槽。
- `OverviewDataModePanel` 只负责地区数据和供需平衡内容，不再拥有导航；同一数据组件通过父级布局类在地区模式呈现为顶部 KPI 条，在供需模式呈现为右侧详情栏。
- `OverviewCommandCenter` 通过 `sideDataPanel` 同步控制供需右栏、地图缩窄和工具栏位置。
- `OverviewPage` 继续拥有当前模式和正式数据请求状态，只调整组件装配，不改变请求、实时刷新或筛选逻辑。

## 可访问性与视觉细节

- 表格使用真实 `table`、列标题和行标题语义；每个行标题同时包含项目名称与正式口径说明。
- 完整表格具备可访问名称，状态文案不只依赖颜色。
- 关键数值保持样本点 KPI 的 DIN 数字字体、青蓝/金色强调和玻璃态边框。
- 1280px 最小指挥舱宽度下不出现页面级横向滚动；长口径文字在项目单元格内换行。

## 验收

- 组件测试证明模式切换与内容面板分离。
- 组件测试证明供需模式同时包含五个核心指标和完整表格。
- 组件测试证明四类缺值语义正确。
- 布局测试证明供需右栏使地图缩窄、工具栏上移且导航不嵌入数据面板。
- 定向测试、格式、lint、架构检查和构建通过。
- 发布到本地受管 `63182` 后，在真实浏览器验证样本点、地区数据、供需平衡三种模式；供需右栏不得覆盖地图，三种模式均无横向滚动和控制台错误。

## 范围外

- 不修改 Backend/Web、数据库、正式数据或供需计算公式。
- 不修改样本点地图、样本数量、边界或图标行为。
- 不提交、合并、推送、切分支、清理或重置现有工作树。
