# 总览监测三维空间讲解设计

## 目标与边界

总览监测面向领导展示与现场讲解，不承担填报、审核或业务处理。页面只读取新后端返回的真实行政区边界、正式业务期间与已核定业务事实；不得在前端复制边界、补造指标或展示无法追溯的示例数字。

正式首层地图只呈现新后端治理范围内的齐齐哈尔市、黑河市、呼伦贝尔市真实边界。用户单击地区查看信息，双击进入县、乡镇、行政村；只有某层真实主数据、边界、父子关系和商用许可全部通过发布门禁后，该层才允许上线。

## 视觉方向

页面采用亮色空间数字孪生语言，参考 Re:Earth、TerriaJS 与 CesiumJS 的地图主导模式，但不复制其界面或示例资源。

- `冰原白 #F5FAFD`：内容背景与远景雾化层。
- `霜蓝 #D9EEF7`：地形基底与非选中区域。
- `北境蓝 #167DB2`：真实边界与空间导航。
- `嫩穗青 #20B99A`：选中地区与产情重点。
- `核定金 #C79736`：已核定、采用值和发布状态。
- `墨松蓝 #153C5A`：标题和正文。

标题采用系统内可用的窄体中文与 `Bahnschrift/DIN Alternate` 数据字形；正文沿用企业平台中文字体栈，避免引入外部字体服务。总览路由进入独立的全视口沉浸展示模式，隐藏业务平台顶栏和侧栏；离开总览路由后，其他业务页面的原有顶栏、侧栏和交互保持不变。总览内容不使用驾驶舱卡片墙、粗边框或常驻三栏。

页面的唯一视觉记忆点是“北境粮情空间图谱”：真实三地边界在 Cesium 场景中形成轻量立体高度，选中地区从霜蓝过渡为嫩穗青，并通过一条空间引导线连接到讲解内容。动效只用于选中、镜头定位和讲解进度；尊重 `prefers-reduced-motion`。

## 页面结构

```text
┌─ 标题 / 产品 / 正式业务期间 / 市场年度 / 地区路径 / 语音状态 ─┐
│                                                              │
│   真实三地三维空间图（约 58%）        选中地区讲解稿（约 42%） │
│   单击选中、双击下钻、可旋转缩放      名称、期间、数据完整性    │
│                                      开始/暂停/停止讲解        │
│                                                              │
├─ 产情脉络 ───────── 市场脉络 ───────── 供需平衡 ──────────────┤
│  只列当前地区核定指标；无数据时说明原因；指标保留来源数量与路径 │
└──────────────────────────────────────────────────────────────┘
```

内容填满浏览器视口但地图本身不独占整屏：宽屏下地图约占内容宽度 58%，讲解层约占 24%，其余空间留给场景呼吸与导航；下方三条业务脉络连续承接页面，不留下无意义空白。窄屏下改为地图、讲解稿、业务脉络的纵向顺序。

## 点击与下钻

1. 首次进入只显示真实三地边界和操作提示，不自动假定当前地区。
2. 单击地区后保持当前镜头上下文，突出选中边界，并请求该地区指标。
3. 双击非行政村地区后，以该地区作为父节点请求下一层真实边界；返回上级恢复上一层父节点。
4. 业务期间、产品或市场年度变化时，取消旧讲解、清空旧指标并重新查询，避免跨条件残留。
5. 指标保留 `sourceDomain`、`sourceCount` 与 `sourcePath`；页面只读展示来源入口，不提供修改功能。

页面顶部同时展示由新后端按有效监测范围实时聚合的覆盖口径：“乡镇 232 个、行政村 2,332 个”。前端不得写死这两个值；乡镇和行政村主数据未通过治理或未导入时，显示当前实际数量及“数据治理中”，不得提前展示目标数量。

齐齐哈尔统计范围只包含龙江县、依安县、泰来县、甘南县、富裕县、克山县、克东县、拜泉县、讷河市和梅里斯达斡尔族区。龙沙区、建华区、铁锋区、昂昂溪区、富拉尔基区、碾子山区保留在行政区主数据中，但不进入监测统计、总览下钻或业务聚合。

## 三组业务讲解

- **产情脉络**：展示 `PRODUCTION` 核定指标，例如面积、产量、品种与质量；具体字段完全由接口结果决定。
- **市场脉络**：展示 `MARKET` 核定指标，例如价格、成交和库存；不在前端推导价格组成。
- **供需平衡**：展示 `SUPPLY` 核定采用值，并把 `LOGISTICS` 指标作为供需流动来源展示；不在前端重算供需公式。

每组按接口原始顺序展示指标名称、格式化数值、单位、核定来源数量和来源域。空组显示“当前条件下暂无已核定数据”，不得以 0 代替缺失值。

## 语音讲解

讲解稿由前端展示层根据当前已加载数据确定性生成，内容顺序为地区与期间、产情、市场、供需平衡、数据完整性说明。讲解只使用屏幕上已经展示的核定值，不调用生成式模型，不把业务数据发送到第三方。

浏览器支持 Web Speech API 时，使用 `SpeechSynthesisUtterance` 和 `zh-CN` 本地/系统语音，提供“开始讲解、暂停/继续、停止”三个状态化操作；切换地区、筛选条件、路由或组件卸载时立即停止旧语音。讲解过程中显示同步文字稿和进度状态。浏览器不支持或语音播放失败时，保留相同文字稿并明确提示“当前浏览器不支持语音播放”。

## 组件与分层

- `OverviewPage`：组合查询状态、地区路径和页面布局，不直接操作 Cesium 或浏览器语音 API。
- `SpatialBoundaryMap`：声明地图输入输出，负责三维组件与可访问 SVG 降级之间切换。
- `CesiumBoundaryScene`：仅负责 Cesium 生命周期、真实几何、相机、拾取与选中材质。
- `RegionNarrative`：把已加载指标按产情、市场、供需三组呈现，不发起网络请求。
- `useOverviewNarration`：封装讲解稿、Speech Synthesis 状态机与清理逻辑。
- `boundaryGeometry`：解析和验证接口 GeoJSON，并向两种渲染器提供统一几何结构。
- `OverviewRepository`：维持应用端口；HTTP、DTO 解码与错误映射仍留在基础设施适配器。

上述组件均位于总览模块 UI 层；领域模型不依赖 React、Cesium 或 Web Speech。外部引擎运行资产由构建脚本准备，生成目录不进入源码审查或 lint。

## 异常与真实性

- 无正式业务期间：仍可浏览真实边界，讲解稿说明指标尚未接入，API 发布门禁继续失败。
- 无真实边界：显示不可展示原因，不绘制矩形、示意边界或用 POI 替代。
- 无某组核定指标：显示缺失状态，不合成趋势、比例或总数。
- WebGL 不可用：退化为同一真实 GeoJSON 的可点击 SVG，并明确标注二维兼容模式。
- 乡镇或行政村缺失：发布门禁阻断相应下钻，不在页面宣称四级完成。
- 请求失败：保留当前有效边界，展示具体失败类型并允许重新选择条件触发重试。

## 风险验证

实现后只执行与本次变化相称的检查：总览组件和讲解状态单元测试、类型/lint/架构检查、生产构建、一次总览浏览器交互验收。验证三地真实边界、单击数据分组、双击下钻、筛选清旧数据、语音开始/暂停/停止、无语音/WebGL 降级和无期间空态。已有全量验证证据在相关代码未变化时不重复执行；最终候选发布仍执行一次完整发布门禁。
