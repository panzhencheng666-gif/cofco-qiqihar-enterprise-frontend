# 总揽监测黄金基线重构设计

## 唯一视觉基线

总揽监测以用户确认的 1672×941 效果图
`/var/folders/qr/ctfpv4694v359kkmjx3fl47m0000gn/T/codex-clipboard-97f26b77-dcb2-4e84-b362-68deef397aa6.png`
为唯一视觉基线。浏览器最终验收使用 1920×1080 的等比例舞台，并在同一比例下对照标题、筛选、六项指标、地图、右侧详情、底部四图和页脚。

效果图是视觉设计稿，不是静态页面资产。正式页面不得把效果图本身作为界面背景，也不得把图中数字、地区或图表数据写入前端。所有文字控件、图表、地图和详情都是可交互代码；业务值只读取正式后端已填报、已审核的结果。

## 布局与设计令牌

- 舞台固定为 1920×1080 的 16:9 构图，并整体缩放适配当前窗口，不改变内部比例。
- 顶栏高 64px；左侧标题、中央三个筛选、右侧审核状态在同一水平线。
- 六项指标位于左侧内容区顶部，采用一体化磨砂带，不拆成六张卡片。
- 地图是页面主视觉，位于指标带与底部图表之间。右侧详情未展开时仍保留其安全区，避免选中后地图跳动。
- 右侧详情只在点击地区后出现；关闭详情不改变地图位置。
- 底部四图为价格趋势、品种结构、各地区播种面积同比、各地区总产量同比。
- 颜色锁定为明亮北境蓝、青蓝玻璃、白色文字、核定金选中态；禁止暗黑驾驶舱或霓虹卡片墙。
- 面板边框 1px、圆角 18–24px、透明磨砂；地图区域不增加独立矩形容器。

## 地表一体化地图

地图采用 Three.js 单画布固定 2.5D 场景，不再使用 MapLibre `fill-extrusion`，也不再使用 CSS 背景加透明地图叠层。

1. 同一 WebGL 画布首先绘制 1672×941 的田园地表纹理。
2. 行政区顶面从真实 GeoJSON 生成几何，并使用与背景完全相同的屏幕空间纹理坐标采样。
3. 行政区外沿向屏幕下方挤出蓝色侧壁和贴地阴影；顶面与背景纹理连续，因此视觉上是地表原位凸起而不是悬浮贴片。
4. 子级行政区只绘制顶面分割线，不重复生成内部侧壁。
5. 选中地区覆盖核定金材质、金色描边、竖向光柱和连接线；未选中区域保持蓝绿色地表材质。
6. 相机、地图缩放、旋转和平移全部固定。工具栏保留视觉外观，但不会改变镜头。
7. WebGL 画布按设备像素比渲染并启用纹理各向异性，避免当前放大模糊。

## 真实多级行政区

层级路径为总体 → 市 → 区县 → 乡镇 → 行政村。

- 总体、市、区县和乡镇只有在接口返回真实边界时才绘制面。
- 行政村使用真实边界；若治理结果明确只提供真实坐标点，则只绘制真实点位，不把父级区域画成行政村。
- 每次进入下一层都重新计算同一地图安全框内的几何适配，完整边界不得被顶部指标、底部图表、右侧详情、左侧工具栏遮挡。
- 点击选中，双击或“进入地区监测”下钻，返回上级恢复正确父节点与固定视角。
- 地区选择包括总体、齐齐哈尔、黑河、呼伦贝尔及接口返回的下级地区；前端不写死齐齐哈尔轮廓或地区集合。
- 缺真实边界时显示治理缺口，不画矩形、近似轮廓或示意地图。

## 业务数据联动

- 六项 KPI、供需平衡、价格趋势、品种结构、播种面积同比、总产量同比和地区详情只读取正式总揽接口。
- 产品、正式业务期间、市场年度和当前行政区共同构成查询口径；切换任一条件立即清除旧选中数据。
- 指标无已审核来源时显示“暂无审核数据”或“数据录入中”，不显示假 0，不合成趋势和比例。
- 右侧详情只在点击地区后出现，内容必须对应当前地区、产品、业务期间和市场年度。
- 图中“粮食商品量”不作为固定 KPI；当前正式 KPI 为接口已定义的平均成交价。

## 组件边界

- `OverviewPage`：只管理查询口径、层级路径、选中状态和仓储端口。
- `OverviewCommandCenter`：代码化实现黄金基线的标题、指标、详情和图表布局。
- `TerrainReliefBoundaryMap`：全新单画布地表与行政区渲染器；不依赖旧 Three、Cesium 或 MapLibre 地图组件。
- `terrainReliefGeometry`：纯函数负责真实 GeoJSON 到屏幕安全框的投影、顶面、侧壁、标签锚点和拾取几何。
- `BoundaryMap`：只负责 WebGL 能力门禁以及真实 SVG 兼容模式。

## 验收门禁

1. 地图从同一田园地表原位凸起，顶面纹理连续、侧壁蓝色、阴影贴地，不悬浮、不面向屏幕立起。
2. 总体、市、区县、乡镇、行政村分别实测，无顶部、底部、右侧、工具栏遮挡。
3. 地图保持主视觉占比且完整边界全部可见。
4. 点击、选中、详情、下钻、返回、关闭详情和筛选切换均使用真实数据。
5. 浏览器以 1920×1080 截图，与唯一视觉基线逐项对照；未达到设计审查级一致时不得宣称完成。
6. 完成总揽监测后停止，未经用户亲自验收通过，不进入行政村导入或任何下一阶段。
