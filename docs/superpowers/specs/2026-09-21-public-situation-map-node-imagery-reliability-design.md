# 公开态势地图节点全显与商业月更影像设计

日期：2026-09-21

## 1. 目标

在不改变现有公开态势地图、四区域行政钻取、权限、业务数据和导航框架的前提下，解决以下问题：

1. 已筛选的自有库、租赁库、历史租赁库和铁路站点在任意缩放级别都不因碰撞策略被隐藏。
2. 地图缩小时，所有图标同比缩小，避免图标遮蔽地图；放大时平滑放大。
3. 相邻或同坐标节点仍分别可见、可点击，并保留真实坐标含义。
4. 选择齐齐哈尔市等地区后，右侧“库点”和“铁路”分类展示该地区的准确数量与全部节点信息。
5. 解决其他电脑上卫星底图不可用、空白、加载过慢，以及滚轮缩放和拖动时长期模糊的问题。
6. 接入有商业授权的月度影像，显示实际采集周期和同步状态，不把卫星底图描述为实时画面。

## 2. 已确认的产品约束

- “全部展示”指每个启用筛选条件下的节点都有独立图标，不使用聚合数字替代节点。
- 图标允许随地图比例尺同比缩放，但不能因为 MapLibre 碰撞检测而消失。
- 同一缩放级别下，各类型设施使用统一的尺寸基准；选中态只增加描边、光环和信息卡，不改变图标大小。
- 境内节点与边界邻近节点继续分开；邻近铁路站点不计入所选行政区的境内总数。
- 原始经纬度不得因视觉避让而被修改或回写。
- 商业影像费用可接受，但密钥、授权范围和供应商凭证不得进入前端包或 Git 仓库。
- 月度影像不是实时视频。页面必须显示影像来源、采集周期、发布时间和最后成功同步时间。

## 3. 节点全显设计

### 3.1 缩放尺寸

设施图标使用连续缩放表达式，而不是固定尺寸：

- 四区域最小总览约 14px；
- 普通总览约 18px；
- 地区视图约 22px；
- 最大细节约 26px。

具体断点由真实浏览器验收微调，但所有库点和铁路站点共享同一缩放曲线。选中态不再改变 `icon-size`。

### 3.2 禁止碰撞淘汰

运营节点图层必须允许并忽略符号占位冲突。所有开启的设施必须进入 WebGL GeoJSON source 和 symbol layer，不能由 `icon-allow-overlap: false` 或隐式 placement 规则删除。

### 3.3 确定性避让

仅打开重叠绘制会造成下层节点不可见，因此增加纯展示层的确定性避让：

1. 保留每个节点的原始经纬度作为业务坐标。
2. 在地图初始化、缩放结束、拖动结束、窗口尺寸变化和筛选变化时，将可见节点投影到屏幕坐标。
3. 对发生视觉碰撞的节点按“节点类型、稳定 ID”排序，在锚点周围按同心环确定偏移位置。
4. 偏移半径随当前图标尺寸同比变化，确保缩小时不会产生过大的视觉占比。
5. 将偏移后的屏幕位置反投影为临时展示坐标，并用独立 WebGL line layer 连接真实坐标和展示坐标。
6. 排列必须由稳定输入决定，避免相同视口下图标随机换位或闪动。
7. 点击图标使用节点 ID 读取原始业务记录；视觉坐标不得进入保存、统计或地区归属判断。

重新布局只在交互结束后执行；滚轮或拖动过程中保留上一版布局，避免每帧计算导致卡顿。

## 4. 地区右侧栏

所选地区的运营设施请求继续使用行政区编码查询。右侧栏的“库点”和“铁路”页签改为完整清单：

- 页签标题显示境内总数；
- 库点页显示自有、租赁、历史租赁分类数量及全部记录；
- 铁路页显示境内站点、邻近站点和境内线路数量，列表默认先展示境内站点；
- 每条记录显示名称、所属行政区、类型、运营状态和已有的来源/同步信息；
- 点击列表项时地图定位并高亮对应节点；
- 点击地图节点时右侧滚动并选中对应记录；
- 清单采用虚拟滚动或窗口化渲染，避免 100 个以上站点阻塞右栏；
- 请求失败时保留上一次成功数据，并在页签内显示具体失败状态，不伪造数量。

## 5. 卫星影像可靠性与性能

### 5.1 同域影像网关

浏览器不再把单一第三方域名作为唯一底图入口。平台后端提供同域影像瓦片网关：

- 商业影像凭证只保存在服务端密钥配置中；
- 网关校验请求范围，只允许四区域及受支持的缩放级别；
- 对允许缓存的授权影像使用对象存储和 CDN 缓存；
- 对上游设置连接/读取超时、有限重试、熔断和健康检查；
- 网关返回标准缓存头、影像版本和采集周期；
- 缓存、代理和再分发必须以最终采购合同许可为准。

### 5.2 永不空白的降级链

地图本体、行政边界、节点和交互不依赖远程影像成功：

1. 当前商业月度影像；
2. 上一期已验证商业影像；
3. 已缓存的稳定高清基准影像；
4. 本地四区域地形着色底图。

任一影像源失败时只切换底图，不销毁 MapLibre 实例，也不影响节点、边界和右侧栏。界面明确显示当前降级状态和实际影像日期。

### 5.3 滚轮缩放与拖动

- 保留已加载的父级瓦片，直到目标层级瓦片可用，避免空白闪烁；
- 为当前视口外一圈瓦片做低优先级预取；
- 取消已经离开视口的请求，限制并发数，避免快速滚轮产生请求风暴；
- 预热四区域初始视图和齐齐哈尔等常用地区的常用层级；
- 高分屏请求授权源支持的高像素密度瓦片；
- 禁止无限 overzoom。超过影像原生分辨率时显示“已达到本期影像原生清晰度”，不能把插值放大称为高清；
- 地形 DEM、矢量道路、字体和影像分别记录失败，不让一个增强源拖垮整张地图。

## 6. 商业月度影像

首选接入具备月度可视镶嵌、XYZ/WMTS 流式服务和像元来源元数据的商业供应商。Planet Visual Monthly 或同等级产品符合当前技术方向；最终供应商以采购授权、对四区域覆盖、国内网络可达性、缓存权利和验收样片为准。

月度更新流程：

1. 每月定时查询上一个完整月份的新影像版本。
2. 核验四区域覆盖、云量、缺瓦片率、采集周期和授权状态。
3. 在候选版本上生成常用层级瓦片并预热缓存。
4. 通过自动检查和人工样片验收后，原子切换活动影像版本。
5. 切换失败时继续使用上一成功版本，并记录失败原因。
6. 页面显示“影像采集：YYYY-MM”“发布/同步时间”和来源；不得显示“实时卫星”。

商业月度影像的原生分辨率不足以提供建筑级实时细节时，高缩放层级使用授权高清基准影像，并分别显示其采集日期。不能把不同日期的影像无标识地混合成同一“实时”画面。

## 7. 数据流与组件边界

- `FourRegionTerrainAtlas`：负责 MapLibre 生命周期、图层同步、交互事件和展示坐标更新。
- 节点布局模块：输入原始节点、视口和图标尺寸，输出不遗漏 ID 的展示点与引线；不访问业务接口。
- `OperationalSituationMap`：负责筛选状态、分类开关和选中项，不承担碰撞计算。
- `OperationalSituationPanel`：负责地区设施数量、完整列表和地图联动。
- 影像配置端口：前端只获得不含密钥的同域模板、活动版本、分辨率上限和采集元数据。
- 影像网关与月度同步任务：属于后端/部署边界，负责授权、缓存、健康检查和版本切换。

## 8. 错误处理

- 节点布局失败时回退到全部重叠绘制，不能回退到碰撞隐藏。
- 个别节点坐标非法时，在右侧栏显示该节点“缺少有效坐标”，仍计入业务清单，但不得伪造地图位置。
- 影像加载失败时保留行政边界、设施节点和本地地形底色。
- 商业影像版本不可用时继续使用上一成功版本，并显示最后成功同步时间。
- 右栏地区设施请求失败时保留上次成功结果并显示错误，不把空响应解释为零节点。

## 9. 测试与验收

### 自动测试

- 运营图层不使用碰撞淘汰，所有开启节点 ID 均进入渲染 source。
- 图标尺寸随 zoom 单调变化，并在最小/最大尺寸内。
- 160 个节点及多组同坐标节点经过布局后 ID 数量不变、位置确定、原始坐标不变。
- 分类筛选只排除未勾选类型，不误删已勾选节点。
- 地区右栏显示准确分类数量和全部记录，境内/邻近统计不混淆。
- 地图与右栏双向选择保持同一节点 ID。
- 影像主源失败时按既定顺序降级，地图和节点仍可操作。
- 快速连续缩放不会触发无界请求或无界布局计算。

### 真实浏览器验收

- Chrome 和 Safari，至少两台不同电脑与两种网络环境；
- 四区域最小缩放、齐齐哈尔市、县、乡镇和村级视图；
- 自有库、租赁库、历史租赁库、铁路站点分别筛选和全部开启；
- 连续滚轮缩放、快速拖动、窗口宽窄切换和高分屏；
- 核对地图可见节点 ID 数量、右栏记录数量与接口返回数量；
- 断开每个外部增强源，确认底图降级但边界、节点和详情不消失；
- 对商业影像核对采集月份、当前活动版本和上一版本回退。

## 10. 发布顺序与完成条件

### 第一阶段：先解决当前问题

- 节点全显、同比缩放、稳定避让；
- 地区右栏完整数量和清单；
- 当前影像加载不阻塞地图，具备明确降级；
- 滚轮和拖动性能改善；
- 完成聚焦测试、构建和本地真实浏览器验收。

### 第二阶段：商业月更影像

- 完成供应商账号、授权范围和密钥配置；
- 上线同域影像网关、缓存和月度同步；
- 完成跨电脑、跨网络与影像日期验收。

“代码完成”“构建通过”“服务健康”“部署成功”和“真实用户浏览器验收”分别记录。只有相应阶段的真实浏览器行为和数据数量核对通过，才可宣称该阶段完成。

## 11. 非目标

- 不改变四区域行政边界、钻取层级和现有业务权限。
- 不修改或伪造库点、铁路站点及其经纬度。
- 不把月度卫星影像宣传为实时视频。
- 不在没有商业授权和缓存许可时抓取、复制或再分发第三方影像。
- 不在本次范围内重构其他总览、样本网络或填报功能。
