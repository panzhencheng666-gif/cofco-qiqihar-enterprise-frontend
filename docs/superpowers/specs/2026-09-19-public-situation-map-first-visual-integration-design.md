# 公开态势地图优先视觉整合设计

**状态：** 用户已批准方案 A。本文补充并收紧《四区域立体农业沙盘设计》的首屏构图、控件布局与验收标准；既有数据、层级、性能和失败降级约束继续有效。

## 单一目标与范围

页面服务于粮情监测人员，单一任务是快速看清四区域地理态势，并在连续缩放中核对地区细节和业务节点。只调整“公开态势”模式，不改变样本点、地区数据、供需平衡等现有地图，不改变导航、权限、行政层级、数据接口、填报流程或已提交数据。

本轮解决四个已确认问题：黑色遮罩形成生硬贴片、右侧详情挤压地图、左上控件堆叠、底部工具与时间轴层次不清。不得借机增加 KPI 墙、装饰性动画、第二张地图或无真实数据支撑的功能。

## 视觉方向

采用“一体化三维卫星农业沙盘”。卫星影像、高程、行政边界和业务图层属于同一个连续地表，不能再出现一块黑色梯形底板承托行政区的效果。

- 四区域内部保留清晰影像与地形起伏，行政边界使用低亮暖白线；选中范围增加克制的金色轮廓。
- 四区域外围仅作为空间上下文，降低饱和度、亮度和信息权重，不显示可交互业务内容，不形成纯黑硬切口。
- 初始视角保持轻度俯视，能够看到地形起伏但不过度透视，四区域主体占地图可用面积约 62% 至 76%。
- 首屏不以通用圆点作为主要视觉。天气、粮库、铁路使用已定义的真实语义图标；库存等统计点保持次级地位。
- 地图是视觉主角，右栏是可滚动的单一详情检查器，控件是安静的辅助层。

### 颜色与字体

- 夜林背景 `#07130f`：地图外围和控件基底。
- 农田绿 `#49644f`：沙盘自然材质的综合色。
- 雾白 `#f3f1e7`：边界、正文和地图图标高亮。
- 谷物金 `#d8b861`：选择状态、时间轴和关键动作。
- 水系青 `#67aeb1`：河湖与弱提示。
- 状态绿 `#4fa878`：正常同步与自有库。

地图与控制使用苹方/微软雅黑，强调中文可读性；右栏地区标题保留宋体形成正式档案感；时间、来源和坐标使用等宽数字特征。不得引入网络字体阻塞首屏。

### 地图与详情栏

- 桌面端详情栏宽度采用 `clamp(390px, 27vw, 460px)`，地图占据其余宽度。
- 详情栏内部独立滚动；标题、分类和主要内容保持清楚，但不得用大面积纯白压过地图。
- 小于 800px 时沿用现有上下分区行为，不把地图和详情栏叠在一起。

### 控件

- 公开态势筛选与“沙盘/融合/实景”在桌面端合并为一条紧凑控制带，使用同一玻璃基底和统一选中状态。
- 节点图层仍为按需展开的唯一图层菜单；不得复制库点、铁路或天气开关。
- 降级提示只在真实失败时出现，置于控制带下方，不占据长期首屏层级。
- 地图标注、缩放、复位和俯视角合并在右下单一工具条；地图标注入口只能有一个。

### 底部信息

- 时间轴保持单行，播放、时间、速度、进度和当前事件依次排列。
- 层级说明位于时间轴上方左侧，地图工具位于右侧，两者不得互相覆盖。
- 来源和许可使用低权重文字放在时间轴边缘，不与当前事件争夺注意力。

## 交互与数据

- 三种地表模式只修改同一个 MapLibre 场景的材质权重，不重建地图、重置镜头或丢失选区。
- 放大时连续出现道路、水系、铁路、中文地名、建筑和公共设施；层级从市到县、乡镇、行政村自动变化。
- 天气、库点、铁路、物流和库存独立更新。任一数据源慢或失败时，地图仍可立即操作，右栏显示已有真实数据和明确状态。
- 外部瓦片请求受四区域根范围约束，显示层以治理边界弱化外围。公共方形瓦片无法在客户端实现行政多边形级“零范围外字节”；如果未来要求严格网络裁切，需要独立的服务端裁切瓦片服务。

## 性能与失败处理

- 公开态势只挂载一个地图实例和一个画布，旧地图不得同时存在。
- 属性变化只更新发生变化的数据源和图层可见性，不能全量同步所有边界、线路和点位。
- SVG 业务图标必须先通过浏览器图像管线解码，再写入 GPU 图层；失败时显示明确降级，不让组件崩溃。
- 投影、远程图层和地形增强只能在样式加载后安装。在线增强失败时保留本地边界与业务图层。
- 页面隐藏时暂停时间轴动画；缩放、切换地表和后台刷新不得增加地图实例数。

## 验收标准

1. 首屏不再出现纯黑矩形或梯形贴片；四区域与外围形成连续地表，区域主体仍清楚突出。
2. 地图在桌面端明显大于详情栏，详情栏宽度不超过 460px，内部滚动且不遮挡地图。
3. 公开态势筛选和地表模式形成一条控制带；地图标注、时间轴、图层菜单均只有一个入口。
4. 1440×810、1280×720、1024×768 和移动断点无控件遮挡、横向溢出或不可点击区域。
5. 实际浏览器中地图实例数为 1、画布数为 1、旧地图数为 0、DOM 地图标记数为 0。
6. 首次进入不空白；业务图标状态和在线增强状态为正常，真实失败时才显示降级提示。
7. 连续切换沙盘、融合、实景以及多次缩放后，地图实例仍为 1，镜头和选区不重置。
8. 放大后能看到对应层级的地区、道路、水系、建筑和公共设施细节；复位恢复四区域总览。
9. 自动化测试、生产构建、受管运行健康检查和真实浏览器截图验收全部通过后，才可称为完成。
