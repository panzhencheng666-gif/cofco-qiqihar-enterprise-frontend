# 总揽地图与样本点联动最终替代设计

## 文档状态

本文是 2026-08-21 总揽页面信息架构的最终权威规格。它只替代《业务目录驱动的总揽地图与联动表格设计》中“地图下方四个业务表格”和“任何地图几何实现均不得调整”的具体段落；既有真实行政边界、行政层级、核定数据口径、权限范围和样本点身份去重要求继续有效。

## 最终信息架构

总揽采用地图优先的单一业务阅读轴：顶部展示服务端核定指标，中部保留真实行政边界与逐级下钻地图，右侧抽屉承载地区摘要、样本点类别、列表和详情。旧设计中的产情、市场、物流、供需四个地图下方联动表格不再渲染，避免与独立业务工作区重复并挤压地图。

地市和区县层级只呈现受管汇总标记，不请求或暴露具体样本点图标。进入更低行政层级并选择业务类别后，才请求授权范围内的具体样本点列表与图标；切换地区或类别时必须清除上一层级结果，迟到响应不得污染当前地图。

## 地图几何边界

允许调整前端地形浮雕网格、显示比例、镜头适配和标签避让，使齐齐哈尔行政边界在当前总揽布局中完整、清晰地显示。调整不得替换或改写权威行政边界坐标，不得改变行政区划父子关系，也不得以视觉网格作为业务坐标或样本点来源。

地图几何回归测试必须证明边界数据输入、行政层级和样本点经纬度合同保持不变；浏览器验收必须覆盖桌面布局、逐级下钻、抽屉联动和空状态。

## 数据与验收

- 顶部指标、地区摘要和样本点只读取 8090 权威服务的核定结果，待审核、退回、作废和身份待核验记录不得进入总揽。
- 缺失值保持缺失并显示来源覆盖说明，不在前端补零或推算。
- 地市层级不调用具体图标接口；进入允许层级后，类别、列表、图标和详情必须保持同一地区与授权范围。
- 前端组件测试、架构检查、格式与静态检查、Node 24 生产构建和 63182 浏览器验收全部通过后，本文替代关系才生效。
