# 区县及更深层真实样本点图标设计

## 目标与边界

正式 63182 总揽地图保持现有几何、行政边界、底图、镜头、标签、右栏比例与结构、首帧 ready、地区点击和逐级下钻。总体层只显示地级市样本点聚合，进入地级市后只显示区县聚合；地图进入区县、乡镇或行政村上下文后，不再请求或显示聚合圆环、数字及聚合可访问文案。

本阶段只实现当前产品、当前授权行政树范围内的真实样本点筛选与图标，不涉及 64185、年度、24h、阶段八、生产或云部署。

## 方案选择

1. 仅前端解除行政村限制：后端会拒绝区县和乡镇图标请求，不能完成目标。
2. 前端拼接每个下级行政区请求：请求数量随行政树膨胀，授权与列表容易失配，不采用。
3. 复用后端现有递归行政树查询，在服务层放宽图标层级并收紧聚合语义：改动最小，授权、状态、产品和事务可见性仍由服务端统一执行，采用此方案。

## 数据与交互

- `sample-point-aggregates` 只接受无 `parentCode` 的总体查询或 `PREFECTURE` 父级查询；结果继续使用不可点击的聚合标记。
- `sample-points`、`sample-point-icons` 和详情都以同一 `productCode`、所选 `regionCode` 及其后代、授权范围、一级 `categoryCode` 和可选二级 `typeCode` 为边界。搜索文本同时约束列表和图标。
- 图标只允许 `COUNTY`、`TOWNSHIP`、`VILLAGE` 查询；`PREFECTURE` 不显示具体点。
- 初次选中区县或更深地区时，右栏只显示分类计数和选择提示，不显示具体列表、图标或详情。
- 点击一级分类显示该类全部；点击二级类型进一步收窄；再次点击当前选项即取消。点击、切换、取消、搜索、切换产品或地区时，同步清空旧列表、旧图标和旧详情，再发起新请求。
- 地图图标仅表达位置和业务类型，不可打开业务详情。只有点击当前筛选结果中的列表项才请求详情；详情继续继承当前产品、地区、分类和类型。
- 右栏关闭、重新打开及浏览器刷新都回到未选分类状态。

## 治理与失败语义

既有 `overview.sample_point_query_source` 只投影已审核业务来源；仓储继续要求样本点已批准，并在图标查询中要求有效坐标。草稿、待审、退回、未提交事务、失败或越权记录不产生图标。缺失或异常坐标只进入 `unresolvedSourceCount` 提示，不产生图标。

任一 API 失败时清空该请求对应的旧结果并显示不可用提示，不把失败解释成零，也不生成替代图标。异步旧响应通过 effect 清理标志丢弃，不能覆盖新的筛选状态。

## 验收

自动化覆盖总体、市、区县、乡镇、行政村五级；一级、二级、取消、切换、搜索、产品、授权、状态、坐标、提交事务、列表—图标—详情一致、右栏关开和刷新。正式 63182 使用 1440×900 与 1920×1080 两档视口截图，并记录地图诊断属性、目标 API 请求参数与响应，证明几何未改变、深层无聚合、筛选后只出现真实图标。
