# 总览监测地图 Blender 混合升级设计

日期：2026-09-21

## 目标

在不改变现有总览监测业务框架、数据接口、权限、标注、图层控制及行政区钻取规则的前提下，为现有四区域地图加入由 Blender 制作并优化的三维资产和交互效果。本阶段只提供本地预览，不发布、不部署生产环境。

完成后的本地预览必须同时满足：

- 默认“样本点”地图和“公开态势”地图都使用同一份 Blender 四区域资产；不得只升级次级标签页。
- 只呈现齐齐哈尔、黑河、呼伦贝尔、大兴安岭，不显示全球地球、海洋或国外区域。
- 使用现有权威行政区几何进行选择、命中和钻取，不用模型近似边界替代业务边界。
- 保留现有天气、库点、铁路、物流、图层筛选、时间轴和标注能力。
- 支持旋转、缩放、悬停高亮、点击聚焦和市到县的首级钻取演示。
- Blender 资产加载失败时自动回退到当前 MapLibre 地图，业务功能仍可使用。

## 非目标

- 不修改后端、数据库、权限模型或正式业务数据。
- 不发布静态资源，不部署本地以外的任何环境，不执行生产切换。
- 不在预览阶段扩展全部县、乡镇、村模型，也不制作无数据支撑的建筑和指标。
- 不替换 MapLibre 的坐标、行政区命中、中文标签和业务图层职责。

## 方案

采用 Blender、Three.js 与现有 MapLibre 的混合渲染：

1. Blender 根据现有四区域权威边界制作轻量三维地形底座、分层边缘和通用设施模型。
2. Blender 输出经过减面、合批和材质压缩的 GLB 资产，资产使用稳定的对象名和区域编码。
3. 前端通过 MapLibre 自定义三维图层加载 GLB，并将其对齐到地图经纬度坐标。
4. MapLibre 继续渲染行政区透明命中面、中文标签和动态业务图层；Three.js 只负责三维地形、设施模型、光效和动画。
5. React 组件继续管理现有选择、钻取、筛选、时间轴和详情面板状态。

默认“样本点”地图已有一套权威 Three.js 行政区场景，因此不创建第二个画布。GLB 作为四区域根级场景内的可选基座加载到同一 Three.js 场景中；现有行政区网格、聚合环、真实坐标样本图标和设计/历史样本层保持在其上方并继续承担命中。进入区县、乡镇或村级后自动移除四区域 GLB，由原有精细行政区场景继续渲染，避免用根级模型冒充下级边界。

## 组件边界

### Blender 资产流水线

- 输入：现有四区域根级行政区几何，以及仅用于视觉起伏的高程采样。
- 输出：四区域地形 GLB、设施模型 GLB、资产清单和尺寸统计。
- 地形与设施分开输出，允许独立加载和降级。
- 所有行政区编码、设施类型和原点信息写入资产清单，不把业务数值烘焙进模型。

### 三维场景图层

- 一个 MapLibre 自定义图层持有唯一 Three.js 场景和渲染器适配器。
- 根据地图投影同步相机，不创建第二套导航系统。
- 根级总览显示四区域地形；进入县级后降低根级模型透明度，由现有多分辨率地图承担细节。
- 组件卸载时释放几何、材质、纹理和动画帧，避免重复进入页面后的显存泄漏。

### 交互桥接

- 悬停和点击首先查询 MapLibre 的权威区域图层，再把选中状态同步到对应三维对象。
- 悬停效果采用边缘增亮和小幅抬升；点击采用镜头聚焦，不改变行政区数据。
- 双击或当前既有钻取手势仍调用 `onRegionDrill`，不让 Three.js 自行推断层级。
- 设施模型点击继续返回现有设施 ID，打开现有详情。

## 视觉设计

- 主色保持当前农业指挥场景的深青绿，降低通用游戏化霓虹感。
- 四区域具有真实地貌起伏和克制的侧缘厚度；边界在卫星、地貌和监测模式下均清晰可见。
- 未选中区域保持足够对比度，选中区域使用暖金色轮廓与局部照明，不使用整块强发光。
- 天气、告警和物流采用局部动画，正常态保持静止，避免长期运行时视觉噪声。
- 中文标签保持屏幕空间渲染，不烘焙进 Blender 纹理，以确保缩放清晰和内容可更新。

## 数据与状态流

`现有接口数据 -> React 状态 -> MapLibre 业务图层与命中面 -> Three.js 视觉状态`

Blender 资产不读取业务接口，也不保存业务状态。选择、钻取、筛选和时间轴仍以当前 React/领域对象为唯一事实来源。

## 加载、错误和降级

- 三维资产使用懒加载，不阻塞当前地图初始化。
- 资产加载期间显示现有 MapLibre 地图，不显示空白占位页。
- 单个设施模型失败时使用现有 SVG 图标；全部三维资产失败时隐藏自定义图层并保留完整业务地图。
- 对低性能设备提供“立体增强”开关，并降低阴影、动画和模型细节等级。

## 本地预览范围

第一版预览包括：

- 默认“样本点”入口中的四区域 Blender 基座、立体增强开关，以及现有/设计/历史样本图层切换。
- 四区域真实边界生成的低多边形三维地形。
- 鼠标旋转、缩放、悬停高亮、点击聚焦。
- 现有根级标签、天气、库点、铁路和物流图层叠加。
- 一个区域的市到县钻取演示。
- Blender 资产关闭或加载失败时的 MapLibre 回退演示。

预览通过现有 Vite 本地开发服务启动，仅绑定 `127.0.0.1`，不上传、不发布。

## 验证

- 资产验证：GLB 可由 Blender 重新打开，模型原点、单位、对象名、三角面数和纹理尺寸符合清单。
- 自动化验证：现有地图测试保持通过，并新增自定义图层生命周期、交互桥接和降级测试。
- 构建验证：TypeScript、Vite 构建和相关地图测试通过。
- 浏览器验证：本地 Chrome 和 Safari 检查四区域总览、点击、首级钻取、图层开关、详情面板及回退。
- 性能验证：重复进入页面不创建多个渲染器；交互期间保持可用帧率，不阻塞业务面板。

## 安全边界

- 本轮只修改 `map` 仓库，不修改存在用户未提交改动的其他前端副本。
- 不使用假业务数据、占位指标或内部编码作为用户界面内容。
- 不发布、不推送、不执行任何生产部署命令。
