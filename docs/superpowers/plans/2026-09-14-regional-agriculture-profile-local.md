# 地区农业概况自动推算与预测本地实施计划

## 本阶段目标

只扩展“总揽监测 → 地区数据”。用户点击地图地区后，右侧显示玉米、大豆、水稻的当年统计/推算结果、种植结构和未来三年预测。样本点和供需平衡保持现状。

## 完成条件

1. 后端提供独立的地区农业档案只读接口，数据与样本点完全解耦。
2. 有正式地区年度数据时按正式数据汇总；缺项由确定性的统计模型补齐，并明确标记“统计值/模型推算”。
3. 未来三年使用线性趋势与保守增长率公式自动计算，响应中返回方法、来源和更新时间。
4. 前端只在地区数据模式且已选择地图地区时打开右侧农业概况栏。
5. 后端针对性测试、前端组件/页面/HTTP 契约测试、构建通过；发布至本地托管运行时并从 63182 真实入口验收。

## 实施顺序

1. 先写后端计算器和接口失败测试，固定三品种、种植结构合计、预测年份和来源标记。
2. 实现应用服务与只读接口，复用现有地区年度数据仓储，不改动填报写入链路。
3. 先写前端仓储与侧栏失败测试，再实现类型、HTTP 解析、侧栏和页面取数。
4. 运行针对性测试与构建，分别提交 backend、map 检查点。
5. 安装到本地托管运行时，复查 API 与浏览器交互。

## 边界

不修改样本点模式、地图钻取、业务导航、供需平衡写入、登录权限和现有地区填报接口。本阶段的自动化含义是业务用户无需为侧栏另行填报；正式地区数据优先，缺失值和未来值由系统公式自动生成。公共网站采集器作为独立后续数据源适配层，不把网页抓取失败传导为页面不可用。
